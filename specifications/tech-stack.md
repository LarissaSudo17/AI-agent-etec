# Stack tecnológica

## Decisão principal

React + TypeScript + SQLite

## Justificativa

- React oferece uma base moderna e ampla para interfaces web.
- TypeScript melhora manutenção, segurança e legibilidade do código.
- SQLite atende ao uso inicial do projeto, com simplicidade de configuração e armazenamento local.

## Objetivos da stack

- Construir uma interface institucional atraente e responsiva.
- Organizar a navegação e o catálogo de cursos de forma clara.
- Suportar a área administrativa para cadastro de notícias.
- Manter uma implementação simples e viável para o contexto do curso.
